# path-to-master-ai-ops

12-недельная программа подготовки к роли инженера по оптимизации LLM-инференса: GPU-ядра, движки serving'а, профилирование, распределённый инференс и экономика cost-to-serve. Старт — 22 октября 2026.

Каждый день сюда коммитится результат: код, замеры, заметки. Будни — час, выходные — три.

## Структура

```
week-NN/                 цели недели и ретро
  README.md
  day-NN-<тема>/         код, замеры, NOTES.md
CALENDAR.md              день → дата → неделя → норма минут
```

## Треки

| Недели | Фокус |
|---|---|
| 1–3 | Ментальная модель и железо: puzzles, свой инференс с KV-cache, roofline, Nsight, Triton-ядра |
| 4–7 | Движок изнутри (SGLang / vLLM), бенчмарки, первые PR, Tensara / GPU MODE |
| 8–10 | Распределёнка (TP/PP/EP, NCCL), cost-to-serve, inference для генеративных рекомендаций |
| 11–12 | Интервью: системный дизайн, теория, ядро на доске, мок-интервью |

## Правила записи

- Папка дня содержит `NOTES.md`: что сделал, что замерил (числа!), что не получилось и почему.
- Замеры — с указанием железа, версии фреймворка и batch size, иначе они бесполезны через неделю.
- Чужой код не копируется без ссылки на источник.
